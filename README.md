# Finite Elements

A collection of finite element projects, computational models, and tutorials, primarily using FEniCSx.

## Tutorials

Tutorials exploring the formulation, numerical solution, and simulation of reaction–diffusion systems using the finite element method.

## Getting Started
Most tutorials use Python and FEniCSx. Where applicable, each tutorial will include its own instructions and dependencies.

To set up the shared environment, if an environment.yml is provided:

```
conda env create -f environment.yml
conda activate fenicsx
```

Run `jupyter lab` to launch Jupyter notebooks, or follow the instructions provided with an individual project.

## Repository Structure

Projects and tutorials are organized by topic. Each tutorial may include example code, notebooks, and instructions for reproducing the results.

## Future Topics

This repository will expand to include additional finite element applications, numerical methods, and computational modeling tutorials.
